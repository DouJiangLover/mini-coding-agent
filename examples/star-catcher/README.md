# 星星捕手：Agent 修复用例

这是一个无需安装依赖的浏览器小游戏，也是 IntentFlow 的故障修复用例。玩家在 20 秒内点击不断移动的星星，连续命中会提高连击数和得分；点击空白区域会中断连击。

## 推荐交给 Agent 的任务

> 修复“星星捕手”小游戏的连击计分错误。连续点击星星时，combo 应持续增加，最高连击和奖励分数也应正确更新。只做必要修改，并运行 npm test 确保所有测试通过。

## 复现故障

```bash
npm test
```

初始版本会有一条测试失败，这是为了让 Agent 根据真实测试输出定位并修复问题。

## 本地试玩

在本目录运行：

```bash
python3 -m http.server 4173
```

然后打开 `http://localhost:4173`。
