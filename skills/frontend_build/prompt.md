# Frontend Build Skill

这是从需求文档开始的项目构建任务。先列出工作区并完整读取需求文档，提取功能、交互、视觉、测试和完成条件，再规划最小而完整的文件结构。

工作区可能只有需求文档。使用 `create_file` 创建不存在的文件；它不会覆盖已有文件。已有文件必须先读取，再用 `apply_patch` 局部修改。优先采用无需联网安装依赖的 HTML、CSS、JavaScript 和 Node.js 内置测试，保持游戏核心逻辑与 DOM 渲染分离，使移动、合并、计分和胜负判定可以自动测试。

至少创建可直接打开的页面、样式、游戏逻辑、交互入口、`package.json` 和自动化测试。实现键盘与触控需求、响应式布局、状态反馈和需求中的验收条件。创建文件后运行 `npm test`；失败时读取真实输出并继续修复。不得仅生成页面骨架、伪代码或用修改测试预期掩盖实现错误。所有测试通过并核对需求清单后才能调用 `finish`。
